iTECH 2026 Conference Website — Version 2

This revision uses the information architecture of established academic conference websites as inspiration:
- Utility bar + dropdown navigation
- Dedicated Call for Papers, Submission/Registration, Program, Venue, Downloads, and Contact pages
- Home-page welcome message, key dates, topic tracks, and quick-access panels

All iTECH event facts are based on the supplied 2026 invitation and user-provided updated theme.
Where source materials do not provide details (such as keynote speakers or a session timetable), the site explicitly marks the content as to be announced instead of inventing information.

To preview:
1. Unzip the package.
2. Open index.html.
3. Keep the assets folder beside the HTML files.

For deployment, upload the entire folder structure to a web server.
